# Dialogue

Dialogues and quests for JumPHP games (`jumphp/dialogue`): branching conversations with conditions and variables in JSON files, a quest log, a typewriter text box.
Documentation: `doc/index.md`; sample: `doc/samples/` (`bin/jumphp extension:add <game> jumphp/dialogue` copies both into your game).
Example game: `games/dialogue-demo`.
